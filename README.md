# Semantic View Editor review

Compiled-only public review build, version 0.0.7.

Open https://kornalexander.github.io/semantic-view-editor-review/ .

Local file editing, conversion and model comparison run in your browser. No Fabric management, model uploads, AI requests or analytics are enabled. Optional autosave stays on this browser profile. Hosting still receives normal page requests.

The implementation repository is not published here. Compiled JavaScript remains inspectable. This preview does not grant a license to proprietary application code; third-party notices accompany the compiled dependencies.
